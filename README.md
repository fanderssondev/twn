# twn — TechWorld with Nana DevOps Bootcamp

My work and exercises for the [TechWorld with Nana DevOps Bootcamp](https://www.techworld-with-nana.com/devops-bootcamp).

## Structure

Each top-level directory maps to a bootcamp module.

- `2-opertaing_systems_and_linux_basics/` — Operating systems and Linux basics: shell scripts, process inspection, node app start/check/log exercises.

More modules added as I progress through the bootcamp.

## Running module scripts

Scripts are self-contained bash. Some download a node project artifact and start a server — re-run after a clean clone:

```bash
cd 2-opertaing_systems_and_linux_basics/8-node_app_with_log_directory
./8-node_app_with_log_directory.sh
```
